# 🚀 Decision Intelligence Pro: AHP Gaussiano

Este projeto transforma a tomada de decisão complexa em um processo puramente baseado em dados. Utilizando o método **AHP Gaussiano**, o software elimina o viés humano ao atribuir pesos automáticos aos critérios conforme a variabilidade das alternativas.

## ✨ Diferenciais do Produto
- **Zero Viés:** Os pesos dos critérios são definidos pela matemática (Fator Gaussiano), não por opiniões.
- **Interface Amigável:** Formulários dinâmicos que dispensam o uso de planilhas complexas.
- **Data-Driven:** Ideal para seleção de fornecedores, contratação de pessoal e investimentos.

## 🛠️ Tecnologias
- **Python 3.9+**
- **Streamlit** (Interface Web)
- **Pandas/NumPy** (Processamento Matricial)

## 🚀 Como Executar
1. Clone o repositório.
2. Instale as dependências: `pip install -r requirements.txt`.
3. Rode o app: `streamlit run app.py`.
